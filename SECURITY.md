# Security

This application may run with administrator rights. Run only code and optional executables you trust. It has no update service or telemetry. Dependency installation and optional upstream downloads require network access; ordinary imaging does not.

Job directories are trusted local inputs, not a secure interchange format for untrusted plans. Do not open someone else's plan or run altered vendor binaries. Do not publish private disk images or raw logs. A maintainer contact must be configured by the repository owner before accepting private vulnerability reports; no contact address is invented here.
