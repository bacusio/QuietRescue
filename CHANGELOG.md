# 1.1.0 standalone preview

- Single Windows x64 EXE bundles Python, Tk and Pillow; ordinary users need no Python installation.
- Frozen worker dispatch preserves piped I/O and checked worker lifetime.
- Native Windows video preview with pause/replay; system-player fallback for unsupported codecs.
- Synthetic photo/video demo and executable acceptance mode; no physical disk access in the demo.
- Portable PhotoRec lookup next to the executable; PhotoRec remains optional and separate.
- Updated English, Traditional Chinese and Japanese guides and evidence-based comparisons.

Physical bad-sector repair, original-name/MFT reconstruction and automatic partition writing remain unimplemented.
