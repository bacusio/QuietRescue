# 使用說明

1. 解壓Windows ZIP，雙擊QuietRescue.exe並允許UAC，不需要安裝Python。PhotoRec的選配安裝見vendor/README.md；鏡像和內建照片還原不需要PhotoRec。
2. 點「刷新硬盤清單」，以型號、序號、容量確認來源。系統／開機碟不能選。不同盤符可能屬於同一物理硬碟；保存位置必須是另一塊健康硬碟上的既有資料夾。
3. 起點／終點是物理byte位址，終點不含；須對齊512或4096邏輯扇區。起點預設0，開始前確認範圍。GB欄是每次啟動的資料上限，不是硬碟容量或排程；預設十進位1GB，如需每批小於1GB可填0.75。
4. 「建立並開始鏡像」會確認目標。每次請求1MiB、分段群組256MiB，先落盤REQUESTED，再讀取，保存資料後記錄GOOD及SHA-256。首次讀錯、8秒回應超時或超過2秒慢讀即停止，並記錄前後最多約1GiB緩衝。這是保守避讓範圍，並非實測壞道邊界；作業系統／韌體內部重試不受程式控制。
5. 「安全停止」在當前操作結束後停止。完整保留任務資料夾：plan.json、map.jsonl與chunk檔不可拆開。以「開啟任務／續讀」選plan.json，再「開始續讀」。包括結果未確認的全部REQUESTED都會跳過，不可刪除紀錄強迫重讀。另建任務不會自動共享映射，也不要同時用其他軟體讀取同一故障盤。
6. 「驗證全部副本」核對區塊雜湊。已驗證容量不等於整盤完成，complete=false表示仍有缺口。「還原照片」從已驗證連續資料提取可解碼JPEG/PNG，候選緩衝上限64MiB，以雜湊命名，不能重建原檔名。
7. 「匯出完整.img」要求選定範圍無缺口，選定範圍不一定是整盤。「匯出已驗證連續區段」會附來源位址，不可跨缺口直接拼接。匯出需要額外空間。鏡像器保留5,000,000,000 bytes加32MiB；PhotoRec採定期空間檢查，並非檔案系統硬配額。
8. 將官方PhotoRec 7.2完整解壓到vendor/testdisk-7.2，再以「影片／更多格式 PhotoRec」處理匯出的副本。輸出保存到健康盤，絕不能寫回故障來源。以「載入還原的照片／影片資料夾」開啟結果；照片與支援編碼的影片可內嵌預覽，暫停按鈕亦可重播已結束影片；其他編碼用系統播放器開啟。需核對全片時長、跳轉與音訊，找到檔頭或程式正常退出不代表影片完整。
9. 「輸出不可分配區域 CSV 草案」只輸出此任務的GUARD。它不建立分區、不標記檔案系統叢集，也不涵蓋其他工具所有故障。沒有SMART壽命／健康度判定。
10. 「CHKDSK /f」會改寫來源檔案系統，不能修復盤體。需完整物理硬碟副本重新驗證、身份與盤符核對，以及輸入序號確認。此公開版未在故障盤實測寫入修復。應從副本提取檔案；沒有鏡像覆寫回源盤按鈕。

## 常見問題

- UAC取消：不會啟動讀盤，準備好後再開啟；不要繞過系統安全機制。
- 序號缺失、跨盤卷或網路目的地：不支援，不要削弱身份檢查。
- 映射無效、雜湊不符、無法確認worker退出：保留映射、日誌與部分檔案，釐清結果前停止續讀。
- 掉線或新增讀取異常：保留斷點，重新開啟UI不會自動重試。
- 搶救目錄放在儲存庫外；不要把鏡像、序號、私人照片或完整日誌上傳GitHub。
