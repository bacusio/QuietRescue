## 問題與改變

單一鏡像分段可能落在影片中間，不能視為完整影片；以往 PhotoRec 中斷也缺少可靠的續作入口。本版加入保存鏡像的 TestDisk 只讀分區分析、PhotoRec 真實 session 續作、跨任務 MKV 拼接驗證及 MFT 原名匯出。

進度色帶顯示已保存、已回報、未確認、故障、跳過及未知範圍，另疊加避讓草案，每 5 秒刷新選定 JSON。套用前核對來源序號與容量。紅色是讀取異常警告，不是精確物理壞道判定；已嘗試不等於已驗證保存。

## 安全與驗證

- 源盤只讀；未知結果及歷史請求不重試。沒有格式化、寫回分區表或壞道寫入修復功能。
- 98 項源碼回歸測試通過。PhotoRec 真實合成中斷 session 已成功續作，照片位元組一致。
- 最新 image-paths EXE 保持使用者指定版本及 SHA-256。前一 resume255 EXE 已通過管理員合成驗收，但本次精確 EXE 的獨立管理員驗收尚未完成，故以 prerelease 發佈。
- 官方依賴安裝腳本已用離線官方 ZIP 實測：校驗 ZIP、兩個 EXE 及終端資料後安裝，未啟動掃描。公開核心包不重分發本地第三方 DLL；首次需安裝官方工具。
- 不包含個人救援檔、硬盤序號、真實跳過地圖或私人日誌。
