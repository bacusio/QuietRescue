# QuietRescue 1.2.0 實作與驗收狀態

## 已完成

- 分開計算每批上限和整個計劃的累計上限；每批結束會保存最終狀態。
- 中斷交易只依目的端資料復核：`RECEIVED` 記錄、區段長度和 SHA-256 全部吻合才補記 `GOOD`；不匹配者標為 `UNCONFIRMED`，不重新讀來源。
- 分類 reader 啟動、權限、來源斷線、CRC、超時／取消、目的地寫入與 flush 錯誤。
- 避讓報表分開標記策略保護、歷史已嘗試、已觀察讀錯與未確認請求；這些標記不代表精確物理壞道。
- 實體 reader 的批准與讀取維持封鎖，直到唯讀來源、異常停讀、worker 退出及重啟復核等硬體驗收通過。

## 驗收界線

目前 19 項自動測試只使用合成檔案鏡像。本次已跑 `py_compile` 及 `python -m unittest -v`，涵蓋分批／累計上限、映射與雜湊復核、錯誤分類、no-retry、空間保留及唯讀分區預覽。

尚未完成：Windows 重建 EXE 的啟動與 GUI 驗收、實體測試設備的 reader/I/O 取消驗收、意外斷電測試，以及完整 NTFS/MFT 和影片/DVD/RAW 還原驗收。1.2 尚不適合實體故障盤讀取；本版不提供物理修復、格式化或分區表寫回。
