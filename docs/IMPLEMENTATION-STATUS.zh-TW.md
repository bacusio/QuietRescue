# QuietRescue 1.2.1 實作與驗收狀態

## 已完成

- 恢復 1.1 的唯讀實體 reader。實體讀取不再被全域硬鎖，但仍必須先審閱並批准與設備、目的地、範圍及政策綁定的計劃。
- 計劃 SHA-256、來源與目的身份、既有避讓地圖新鮮度、歷史 REQUESTED 排除、來源序號互斥鎖與不重試政策仍在讀取路徑中執行。
- 分開計算每批與整份計劃累計上限；中斷請求只有在 journal 收據、片段長度及 SHA-256 相符時才會復核為已保存。
- 分類 reader 啟動、權限、來源斷線、CRC、超時、目的地寫入與 flush 錯誤。讀取錯誤不會自動重試。
- 進度色帶按來源序號與容量核對進度 JSON，只呈現進度，不會自行啟動讀盤。
- 不提供壞道寫入修復、格式化或分區表寫回；避讓輸出是草案，不能證明候選範圍健康。

## 本次驗證

目前 20 項自動測試使用合成檔案與進度 JSON，涵蓋唯讀鏡像流程、雜湊復核、超時不重試、批准綁定計劃、未批准前不啟動 reader、空間保留及唯讀預覽。沒有讀取或寫入實體來源盤。

本次建置沒有啟動 EXE，沒有實際 UAC 點擊驗收，也未在故障硬碟上驗證 USB I/O 取消或韌體內部行為。故障盤使用風險仍需按使用者選定的範圍自行評估；系統／裝置層重試不受應用程式控制。
