# 使い方

1. Windows ZIPを展開してQuietRescue.exeを開き、UACを許可します。Pythonは不要です。PhotoRecは任意です。導入方法はvendor/README.mdを参照してください。
2. 「刷新硬盤清單」でモデル・シリアル・容量を確認します。システム／起動ディスクは対象外です。異なるドライブ文字でも同一物理ディスクの場合があります。保存先は別の正常な物理ディスクにある既存フォルダーを選びます。
3. 開始／終了値は物理バイト位置で、終了値は含みません。512または4096バイトの論理セクター境界に合わせます。開始値の初期値は0です。GB欄は1回の開始あたりの上限です。初期値は十進1GBで、1GB未満にする場合は0.75を指定します。進捗帯から `disk-rescue-progress/v1` JSONを選ぶと5秒ごとに更新します。シリアル番号と容量が完全一致した場合のみ範囲を表示し、青いカーソルのドラッグは開始バイト欄に反映されます。JSONだけを読み取り、ディスクI/Oは開始しません。
4. 「建立並開始鏡像」で対象を確認します。要求は1MiB、セグメントのグループは256MiBです。I/O前にREQUESTEDを永続化し、保存後にGOODとSHA-256を記録します。最初の読み取りエラー、8秒の応答待ち、2秒超の読み取りで停止し、前後最大約1GiBの回避範囲を記録します。実測した不良セクター境界ではありません。OSやファームウェア内部の再試行は制御できません。
5. 「安全停止」は現在の操作後に停止します。plan.json、map.jsonl、全chunkファイルを一緒に保存します。「開啟任務／續讀」でplan.jsonを開き、「開始續讀」で再開します。結果不明を含む全REQUESTEDを除外します。記録を削除して再試行しないでください。新規ジョブ間のマップ共有は自動ではなく、別ツールによる同じ障害ディスクの並行読み取りも避けます。
6. 「驗證全部副本」はブロックのハッシュを確認します。検証済み容量はディスク全体の完成を意味しません。complete=falseは欠落ありです。「還原照片」は連続した検証済みデータからデコード可能なJPEG/PNGを抽出します。候補バッファは64MiBまでで、名前はハッシュです。
7. 「匯出完整.img」は選択範囲に欠落がない場合のみ使えます。選択範囲は必ずしもディスク全体ではありません。「匯出已驗證連續區段」は元の位置付きで個別領域を出力します。欠落をまたいで連結しないでください。書き出しには追加容量が必要です。イメージ作成は5,000,000,000バイト＋32MiBを残します。PhotoRecの空き容量確認は定期的で、厳密なファイルシステムのクォータではありません。
8. 公式PhotoRec 7.2一式をvendor/testdisk-7.2に展開し、「影片／更多格式 PhotoRec」で書き出したコピーを処理します。出力先は正常なディスクにし、障害のある元ディスクには保存しません。「載入還原的照片／影片資料夾」で結果を表示できます。写真と対応コーデックの動画は画面内で表示します。一時停止ボタンで終了した動画も再再生できます。非対応形式はシステムプレーヤーで開きます。全編の長さ、シーク、音声を確認してください。正常終了やヘッダー検出だけでは完全な動画とは判断できません。
9. CSV出力はこのジョブのGUARDだけを含む回避案です。パーティション作成やクラスタの使用禁止設定は行いません。他ツールの全障害も含みません。SMART寿命・健康度の診断はありません。
10. CHKDSK /fは元のファイルシステムを書き換え、物理故障は修理しません。物理ディスク全体のバックアップ再検証、ディスク・ボリューム確認、シリアル入力が必要です。この公開版では障害ディスクへの修復書き込みは実測していません。コピーからのファイル抽出を基本とし、元ディスクへイメージを書き戻すボタンはありません。

## 問題が起きた場合

- UACをキャンセルすると読み取りは開始しません。必要になったら再起動し、セキュリティ機構を回避しないでください。
- シリアル不明、複数ディスクにまたがるボリューム、ネットワーク保存先は未対応です。
- マップ破損、ハッシュ不一致、worker終了不明の場合は停止し、ログと部分データを保存してください。
- 切断や新規エラー後はチェックポイントを保持します。UIを開くだけでは再試行しません。
- 復旧データはリポジトリ外に置き、イメージ、シリアル、個人写真、完全なログをGitHubに投稿しないでください。
